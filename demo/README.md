# FlareWise browser app

From this directory, `npm ci` then `npm run dev -- --port 5174`. Build with `npm run build`; preview with `npm exec vite preview -- --port 5173`.

The production loader uses only `/data/manifest.json` and its assets. No dummy-data fallback exists. The shared baseline loads once; exact plan residuals load lazily and remain cached for the session. A failed load retains the prior complete scenario and pauses playback. Period-average and hourly views share fixed source installations and legend thresholds.

Earth → South Texas → inspect source/community → replay real wind → choose budget and investment objective → compare before/after → inspect sampled frontier and assumptions. Basemap can be disabled under Layers for local Census-geography viewing. Reset restores the $5m Financial annual-baseline defaults; Back to Earth preserves regional work.

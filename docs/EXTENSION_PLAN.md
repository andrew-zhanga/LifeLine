## Judge journey and quality bar
Global inventory → Texas investment decision → financial/community comparison → follow a source's time-dependent plume → install capture → inspect community benefit → stress-test assumptions. Satellite segmentation is a separate research experiment, not evidence validating flare emissions or health outcomes. Prioritize beautiful, responsive, coherent interaction over number of features. Existing annual metrics remain labeled screening-v1 and must not be confused with bounded transport replay results.

Visual direction: scientific simulation workbench, expansive dark graphite viewport (#151a22), muted steel surfaces (#26303b), warm source amber (#f4b36b), pale smoke (#d7e3ec), community cyan (#81cbd3), capture mint (#a8dfbc). Restrained existing sans typography, compact readable controls, timeline at bottom, contextual inspector right. Smooth orbit, zoom and timeline interpolation. No giant opaque dashboard cards obscuring the plume. Distinguish illustrative schematic structures from observed terrain/buildings. Target 60 fps, report measured median/p95 and degrade particles/render scale to keep interactions responsive. Respect reduced motion, stop hidden render loops, dispose GPU resources.

## Shared interfaces and handoffs
Workers publish schema and tiny actual example early, before full build. Use JSON artifacts with schema_version, model_version, provenance, assumptions, limitations. Transport and decision are distinct models. Each worker sends artifact/schema details directly to frontend and coordinator. Every meaningful checkpoint: tell peer which fields changed, request an independent cross-check, respond to peer findings. No shared-file edits without explicit handoff. A and B cross-review calculations; C checks UI-facing ranges, IDs and timestamps; coordinator reviews integration. Workers never Git commit/checkout/reset/push.

Transport contract: output data/build/transport/scene.json and diagnostics.json. Scene must contain geographic source/receptor positions, timestamp/frame definitions, stable source IDs, local-coordinate convention, plume geometry/particle trajectories or compact puff state, source weights, baseline/90%-capture receptor curves derived from same states, actual weather vectors, bounds and assumptions. Capture at a specified time scales newly emitted mass only; already emitted mass persists. Preserve per-source identity to render selected-source intervention. Bounded subset/window explicitly stated. No pollutant concentration claim without emission factors. An initial puff scene is required early. Frontend may use Three.js if that delivers smooth quality with fewer dependencies than Cesium; geographic context and honest schematic labeling required. No fake Street View or terrain.

Community contract: data/build/community/community.json and robustness.json. Existing plan IDs/budgets must match original outputs. Tract population counts are real ACS allocated cells; list baseline, residual, reduction and top source contributions. Provide all-resident/under5/65+ objectives with actual optimized site IDs and economics. Avoid summing overlapping Census places. Robustness must use explicit scenario definitions, held-out weather slices if any, performance ranges not probabilistic confidence. Selection frequency refers to defined scenario solves, not probability. Keep original annual model separate from transport replay.
